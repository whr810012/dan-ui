## API

### Props

| 属性 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| modelValue | 绑定值 | `string` | `''` |
| rows | 行数 | `number` | `3` |
| maxlength | 最大长度 | `number` | — |
| showWordLimit | 显示字数统计 | `boolean` | `false` |
| disabled | 禁用 | `boolean` | `false` |
