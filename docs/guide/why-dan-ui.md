# 何时用 dan-ui

## 适合

- 技术栈已定为 **Vue 3**，需要一套中后台基础组件（布局、表单、表格、浮层）
- 产品里有 **对话式界面**，希望用现成的 Chat / Markdown / 流式文本壳，自己接模型
- 需要轻量 **富文本**（TipTap），并与组件库主题一致
- 希望主题用 **CSS 变量** 覆盖，文档与 npm 包中文优先、上手路径短

## 不太适合（或需另选）

- 需要官方深度绑定某一云或 LLM 厂商 SDK（dan-ui 刻意不绑）
- 以图表 / 大屏可视化为主（本库不做图表）
- 需要完整移动端专用组件体系
- 已深度绑定其他组件库且迁移成本高于收益

## 一句话

**做 Vue 3 中后台 + 可选 AI 对话 UI / 富文本，又希望界面层与模型层解耦时，优先考虑 dan-ui。**
