## dan-ui 是什么

**dan-ui** 是一套面向**中后台与 AI 应用界面**的 **Vue 3** 组件库。npm 包名为 `@dandan-ui/ui` 与 `@dandan-ui/theme`，官方文档为 [https://dandanhub.vip/dan-ui/](https://dandanhub.vip/dan-ui/)。

它**是**：可主题化的 UI 组件（表单、表格、浮层、Chat 壳、富文本编辑器）。  
它**不是**：大模型 SDK、图表库、或绑定某一云厂商的上传 SDK。

适用场景：管理后台、运营系统、需要对话式界面但不想自研基础控件的 Vue 3 项目。选型说明见 [何时用 dan-ui](/guide/why-dan-ui)。
